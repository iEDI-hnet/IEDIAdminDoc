# Tools overview

The **Tools** section contains configuration, monitoring, and internal communication utilities.

| Menu | Route | Access |
|------|-------|--------|
| Superuser | `/superuser` | `superuser` role |
| Internal blog | `/internal-blog` | Authenticated staff |
| Feedback and Issues | `/admin/feedback` | Admin roles |
| Configuration | `/quicksetup` | Quick setup wizard |
| Overwatch | `/overwatch` | Support billing / cases |
| ABC | `/abc` | Danish partner lookup |

## User shortcuts (iframes)

Routes `/user1` … `/user7` render embedded external apps via `userAppContent`. They are not listed in the main sidebar inventory; access may be direct URL only.
