# Networks overview

The **Networks** section configures how iEDI connects to external networks and national infrastructures.

| Menu | Route | UI type |
|------|-------|---------|
| Protocols | `/protocols` | Table + detail form |
| as2 | `/as2` | Embedded AS2 console (iframe) |
| D.U.C | `/duc` | Placeholder (Todo) |
| iEDI | `/endpoints` | Table + endpoint detail |
| KMD | `/kmd` | Placeholder / route only |
| eDelivery DK | `/nemhandel` | Multi-tab DataTables |
| PPF (FR) | `/ppf` | France annuaire (4 entity types) |
| Tieto FI | `/tieto` | External iframe (Todo) |
| NRS Error Codes | `/nrs_error_codes` | Table + section widgets |

Most network list pages use the active **dimension** except PPF, AS2, Tieto, and placeholders.
